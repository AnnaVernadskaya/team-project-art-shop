# Team Project — Art Shop

Учебный командный проект RS School — интернет-магазин картин. В приложении можно просматривать каталог, добавлять картины в корзину, удалять их и видеть общую стоимость заказа.

На стартовой странице «О нас» представлена команда и описан вклад каждого участника.

## Структура проекта

Приложение находится в корне репозитория. Данные каталога хранятся в проекте.

## Планируемый стек

- TypeScript — логика приложения
- HTML и CSS — разметка и стили
- Vite — локальный запуск и сборка
- Vitest — unit-тесты

## Запуск проекта

После настройки приложения команды выполняются из корня репозитория.

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который Vite выведет в терминале.

## Работа с ветками

- `main` — версия для деплоя и основа для веток сдачи.
- `dev` — общая ветка разработки. Здесь объединяем и проверяем изменения обоих участников.
- `feat/<название-задачи>` — ветка для новой функции, например `feat/catalog` или `feat/cart`. Для исправлений используем `fix/<название>`.

### Как работать над задачей

1. Возьмите задачу на доске и переведите её в статус **In Progress**.
2. Обновите локальную `dev` и создайте от неё ветку задачи.
3. Сделайте изменения и коммит, например `feat: add paintings catalog`.
4. Откройте Pull Request из ветки задачи в `dev`, добавьте ссылку на задачу и запросите ревью у напарника. Переведите задачу в **In Review**.
5. После ревью и слияния PR переведите задачу в **Done**.

### Деплой и сдача

Когда приложение готово, проверяем его в `dev`, вливаем изменения через общий PR из `dev` в `main` и деплоим из `main`.

Для cross-check каждый участник создаёт свою ветку `submission/<github-login>` от обновлённой `main`, добавляет файл `submissions/<github-login>.md` с описанием вклада и ссылками и открывает личный PR в `main`. PR остаётся открытым до окончания проверки.
